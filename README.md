# AWS Cognito React Login App

A full-featured React Login App with:

- AWS Cognito Hosted UI integration
- React Router v7
- Testing with Jest + React Testing Library
- Linting and CI via GitHub Actions
- Deployment on Vercel
- No `.env` files required
- Docker-ready
- Upcoming: MongoDB Atlas, AWS S3, Python API
